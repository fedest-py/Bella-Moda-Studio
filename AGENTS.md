# Bella Moda Studio

This repository is the canonical source of the Bella Moda Studio website. Make future changes here, preserving history; do not create another independent repository or migrate to a site builder.

Preserve the existing design, text, responsive layout, photography, and animation unless the owner requests a change. Images in web/assets are the real store assets; do not replace them with generated artwork. The existing system-font stacks are intentional and must stay unchanged to preserve appearance on each device.

Use Node 22 or later. Run npm run check before committing. Static output is dist/; Cloudflare Pages bundles functions/ separately during Git integration builds. Keep secrets out of source and assets. Google live hours/ratings are optional and inactive without server-side environment values. Do not claim they are live until a real successful listing request has been verified.

Do not deploy or configure hosting/domain settings unless explicitly requested. Update this same repository for subsequent modifications.
